# Task tracking

Tasks are intentionally low-ceremony. They live where the work is, not in a
separate task system.

## Where tasks live

- **Day-to-day tasks** live in the daily note's `## ✅ Tasks` section as
  checkbox lines: `- [ ]` open, `- [x]` done.
- **Project tasks** live in that project's `Next actions` section.
- There is no global task list and no inbox. If something needs to happen, it's
  a checkbox in a daily or a project — nowhere else.

## Carry-forward

`/daily` carries **unchecked** tasks forward from the previous daily into
today's note, so nothing open is silently dropped. Checked tasks stay in the
daily they were completed in — that's the record. Carry-forward copies the open
ones; it does not nag about how long they've been open.

## Appointments and deadlines

Time-bound things are **not** tasks — they live in `Agenda.md`, managed by
`/agenda`. The daily's "📅 Today" line is populated from there. Keep deadlines
out of the task list so the task list stays about action, not dates.

## Tone

No priorities flair, no due-date scoring inside tasks, no streaks. A task is a
checkbox. If it matters and is time-bound, it's in the Agenda; if it's just to
be done, it's a checkbox in the daily or project.
